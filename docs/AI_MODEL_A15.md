## 3. 业务边界

- 模型输出候选框，不直接给出整批合格判定；未检出不等于正常/A级。
- A11 的面积分母是整幅图像，不是果实表面积或真实受损面积。
- A12：low→B、moderate→C、high→D；none_observed→null。该值仅为开发规则建议。
- `suggested_grade` 不覆盖人工 `final_grade`。人工确认目标存在也不自动确认等级。
- B 加工流程只能使用团队批准并明确记录来源的人工业务输入，不把单图建议静默提升为批次等级。
- 公共溯源只公开授权摘要；原图、候选框、模型内部元数据和人工内部备注仍不公开。
