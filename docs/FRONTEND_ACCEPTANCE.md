# 六模块骨架验收清单 v0.2

## 1. 已在制作环境执行的检查

本制作环境为 Linux，Node.js 22.16.0 / npm 10.9.2，不是用户的 Windows 开发机。本包的纯 JavaScript 单元测试共 29 项，覆盖批次 ID、跨页面批次参数、空值、事件覆盖、链接校验、HTTP 错误、公共接口与未接入功能不发请求。

这些单元测试使用 HTTP 替身，不代表已经连接真实 Spring Boot/MySQL。另完成 10 项更新脚本测试（临时 Git 仓库），覆盖备份、重复应用、冲突拒绝、主分支拒绝、嵌套目录拒绝、校验和及 CRLF；并进行了 JavaScript/模板表达式与相对导入静态检查、CSS 语法检查。这些不替代 Vue 编译器或浏览器运行检查。

制作环境无法连接 npm 注册表安装依赖，所以未在这里执行 Vite 生产构建、Vue 编译器检查、真实浏览器端到端回归或二维码扫码验收。随包提供 `npm run check:vue`，用于安装依赖后编译检查全部 Vue 组件。不能把单元测试通过描述成全栈验收通过。

## 2. 你本机的必做检查

保持 MySQL 和后端运行；先在前端窗口停止旧 Vite 进程，再应用更新包。在项目 `frontend` 中依次执行：

```bat
npm install
```

```bat
npm run check:vue
```

```bat
npm test
```

```bat
npm run build
```

任意一步出错先停止，不继续提交。通过后执行 `npm run dev`，打开浏览器检查下面的清单。

在另一个 CMD 回到项目根目录执行：

```bat
cd /d D:\Projects\ZhiJian
```

```bat
python scripts\smoke_batch.py
```

原冒烟脚本验证列表、详情、公开溯源、重复编号、缺失批次，不验证新页面、图片推理、规则建议或告警功能；本次没有修改它。

## 3. 页面回归

| 检查 | 预期结果 |
| --- | --- |
| 打开首页 | 六个入口存在；登记数来自当前 API；无数据时为 0，接口失败时为 `—` |
| AI 待复核数 / 告警数 | 尚未接入，显示 `—`，不能显示伪造业务数字 |
| 打开批次列表、搜索编号 | 使用真实批次；搜索不写入数据 |
| 新建一个独立测试编号 | 返回真实数据库生成的 ID，并跳到该批次详情 |
| 再创建相同编号 | 友好的重复编号提示，不出现成功提示 |
| 从详情进入三个业务页 | 各页保留相同 batch_id，并显示正确批次编号 |
| 从下拉框切换批次 | 旧批次内容与本地表单清空；不串结果 |
| 直接打开无效 batch_id | 错误提示，不静默选别的批次 |
| AI 页选择 JPG/PNG/WebP | 只本地预览；所有模型与复核操作明确待接入 |
| AI 页选择错误格式或 >10 MiB | 拒绝选择，不上传 |
| 加工页填写草稿后切批次 | 草稿清空，没有网络写入和假建议 |
| 冷链页选择 CSV | 只展示文件名，不伪造曲线或告警 |
| 溯源页打开公开时间线 | 使用 /trace 接口，不把全部内部事件直接公开 |
| 打开记录预览 | 带“非正式质检报告”提示，仅显示真实现有记录及未接入说明 |
| 公开页 | 没有内部供应商字段、管理菜单；刷新仍可访问 |
| 公开页不存在的编号 | 错误状态，无上一批次残留数据 |
| 浏览器前进、后退和直接刷新深层路径 | 路由正常；现有 Nginx 的 SPA fallback 保持可用 |
| 停止后端后点刷新 | 明确报错；不以空记录或假成功隐藏故障 |
| 手机打开公开页 | 文字、时间线可读，无横向溢出；同网络二维码有效 |

新建测试批次是实际写库行为，只在本地开发库进行。不要为了清理测试数据删除整库。
