## 本机安装

使用配套 `ZhiJian_Frontend_20261016.zip`。关闭运行 5173 的 Vue 窗口，解压并运行 `UPDATE_FRONTEND.cmd`，默认目标是 `D:\ZhiJianData\ZhiJian-latest-20261015`。工具会先核对全部待更新文件；检测到本地冲突或包文件损坏时，在写入前停止。更新前备份到目标目录同级的 `ZhiJian-ui-backups`；失败时回滚本次已经写入的文件。

后端、8001、8002 和 MySQL 可以继续运行。安装后在目标仓库执行 `python scripts\app_local.py web`，打开页面并按 Ctrl+F5。依赖未改变，不需要重新建库或安装 Python 依赖。
